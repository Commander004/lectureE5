# 🌍 GRAVITY — Interactive Lecture

> **What if gravity suddenly disappeared?**

An interactive physics experience built as a website instead of a traditional PowerPoint.

---

## ✨ Live Demo

**[Open the lecture →](https://commander004.github.io/lectureE5/)**

> Enable GitHub Pages first (Settings → Pages → Deploy from branch → main)

---

## 🎮 Controls

| Action            | Desktop              | Mobile              |
|-------------------|----------------------|---------------------|
| Start             | `Enter`              | Tap **→**           |
| Next Scene        | `→` Right Arrow      | Tap **→**           |
| Previous Scene    | `←` Left Arrow       | Tap **←**           |
| Toggle Gravity    | `G`                  | Tap **G** button    |
